# SmartLLM Architecture (`docs/ARCHITECTURE.md`)

## 1. Donor Model (`Qwen/Qwen3.8-Flash-Next`, `qwen4_exp`)
Verified directly against `model.safetensors.index.json`, the 131 `.safetensors` headers, `transformers` `modeling_qwen4_exp.py`, and mainline `llama.cpp` (`research/step5_6_layer_shard_schedule.json`):
- **Core dims:** `num_hidden_layers = 48` (`36` GDN `linear_attention` + `12` QSA `full_attention`, interval `4`), `hidden_size = 2560`, `vocab_size = 248320`.
- **MoE & Shared Expert:** `num_experts = 512`, `num_experts_per_tok = 10`, `moe_intermediate_size = 640`, `shared_expert_intermediate_size = 640`.
- **Hyper-Connections (HC):** `hc_count = 4`, `hc_lowrank = 320`, wide residual stream `4 × 2560 = 10240` (`attn_hyper_connection`, `mlp_hyper_connection`, root `hyper_connection_mixer`; no standalone `model.norm`).
- **Per-Layer Embedding (PLE):** `ple_layer_ids = [2]` in `config.json` is **1-based** → maps to **0-based `model.language_model.layers.1.ple.*`** (`137` tensors, `102.47 GB` in shards `00005..00037`, `128` shards of `[2500012, 160]`).
- **Vision & MTP:** `model.visual.*` (`333` tensors, `0.898 GB` in shard `00001`); `mtp.*` (`31` tensors, `5.214 GB` across shards `00037..00124`, expert tensors in `00060` and `00062`).

## 2. Production `SmartLLM v2` Surgery & Quantization (`K=320`, CachyOS Linux)
- **Domain-Aware Closed-Loop Pruning (`A4_prime K=320/512` + `C3` healing):** `Wave 1–3` pruned `512 → 320` routed experts across all `48` transformer layers + `blk.48` MTP (`K=320`, `640` calibration sequences) and healed router/expert projections on `eval/calibration` (`EN + RU` Web/Design/Code).
- **2-Bit & Mixed-Precision Quantization (`V1: IQ3_XXS + GSQ Q2_0`):** Produces `models/SmartLLM-v2-K320-V1.gguf` (`55.01 GiB`, alongside `models/mmproj-Qwen3.8-Flash-Next-BF16.gguf`, `866 MiB`). Protects dense bottlenecks (`per_layer_token_embd`, `hc_*`, `indexer`, output head) while keeping `ffn_down_exps` in `IQ4_NL` / `GSQ Q2_0`.

## 3. Zero-Swap Direct NVMe Runtime & Sequential GPU Sharing
- **Mandatory `llama-server` Flags (`127.0.0.1:18080`):** `-fit off --lazy-mode direct --n-cpu-moe 42 -nr --moe-cache-mib 2048 --moe-cache-cpu-share 0.00 -fa on -ctk q8_0 -ctv q8_0 -c 32768 -ub 512 -ngl 99 -np 1 --cache-ram 0 --ctx-checkpoints 0 --no-cache-prompt --reasoning off --reasoning-budget 0 -ot blk\.48\..*=CPU` paired with a periodic `POSIX_FADV_DONTNEED` page-cache trimmer.
- **Verified SLA & Benchmarks (`eval/suite/runs/smartllm-v2-k320-v1/run_summary.json`):** `26.82 GiB` `PLE` stays at **`0 B` resident RAM** via direct NVMe `pread`; **`0 B` disk swap** across `20m 32K soak` (`17.502 tok/s`) and `18` Wave 4 tasks (`21.14 tok/s` mean).
- **Sequential `LLM ↔ Z-Image` GPU Handoff:** `GPUEngineController` (`studio/smartllm_studio/engines/gpu.py`) + global `operation_lock` ensure `llama-server` is fully terminated (`cleanup_children`, `0` compute VRAM) before `sd-cli` (`Z-Image-Turbo`, `q8_0`, `--clip-on-cpu --vae-tiling --sampling-method euler --flow-shift 3.0 --steps 8 --cfg-scale 1.0`) renders batches.

## 4. `SmartLLM Studio` & Deterministic Compiler (`studio/smartllm_studio/`)
- **Sub-Agent Decision Pipeline (`pipeline.py`, `PIPELINE_VERSION = 10`):** LLM agents emit structured JSON decisions only (never raw HTML/CSS) over disk-backed memory (`smartllm.md`, `.smartllm/state.json`, `.smartllm/memory/*.json` with SHA-256 fingerprint resume): `foundation` (single source of truth for brand, contacts, `products`/prices, `history`, canonical `team` w/ `gender`, `features`, `stats`, `process`) → `architect` (`quest` + non-portrait `hero_subject` + 2 `gallery_subjects`) → `structure` → `hero` → `copy` + `_sync_page_copy_to_foundation` → `seo` → `visuals` (`brand-logo.png`, per-page heroes, gallery, gender-locked `3:4` headroom `team` portraits) → `localize` → `review` (`_accept_review_fix`, `6/6`) → `sd-cli` slot-matched render (`resolve_slot_dimensions`, `576×768` portraits).
- **Deterministic Compiler & Audit (`blueprint.py`, `blueprint_render.py`, `canon_cards.json`, `canon_dossiers.json`):** Compiles multi-page HTML5, OKLCH `tokens.css`, dossier-driven motion/micro/surface interactions, `3:4` `object-position: 50% 15%` portraits, `read_png_dimensions()` HTML image sizing, `data-count` `2×2` grid symmetry, `en+ru` `slm-lang` switcher, escaped `JSON-LD` `@graph` (`Organization`/`Product`/`Offer`/`FAQPage`), `llms.txt`, and exact SHA-256 CSP headers (`final_audit.json`), backed by the offline CPU + Chromium/Lighthouse gate (`studio/tests/test_studio_cpu.py`, `227` controls, LH `100/100`).
